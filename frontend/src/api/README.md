# 서버 호출

API 요청 함수를 관리합니다.

계약은 저장소 루트의 `docs/api-contract.md`, 응답 타입은 `../types/api.ts`를 함께 확인합니다. 개발 서버에서 `/api` 요청은 백엔드의 `127.0.0.1:8000`으로 전달됩니다.

- `client.ts`: 상태 API를 호출하는 `getHealth()`.
- `issueApi.ts`: 저장소 분석, 작업 상태, 검색, Issue 상세, 요약 요청 함수.
- `fixtures/mockData.ts`: 검색·상세·요약 Mock 데이터.

검색·상세·요약 함수는 503 응답이나 요청 실패 시 Mock 데이터를 반환합니다. 백엔드 모듈을 연결한 뒤에는 Mock 사용 여부를 화면에 표시하거나 대체 동작을 제거하는 것을 검토합니다.
